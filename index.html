과목별 개념노트, 기본 CBT, 모의고사, 오답노트, 학습기록을 한 곳에서 관리하는 순수 HTML/CSS/JavaScript 정적 사이트입니다.

학습 메뉴

ADsP 개념정리

데이터 이해, 데이터 분석 기획, 데이터 분석 과목별 핵심을 정리합니다.

ADsP 기본 CBT

핵심 개념을 점검하는 50문항 객관식 문제 풀이입니다.

ADsP 모의고사 1회

실제 시험 흐름에 맞춘 50문항 모의고사입니다.

오답노트

틀린 문제를 과목별로 다시 확인하고 복습합니다.

학습기록

풀이 수, 정답률, 최근 풀이 로그를 브라우저에 저장합니다.

source 자료실

source 폴더에 있는 ADsP 자료의 반영 상태와 수동 검수 대상을 확인합니다.

내 학습기록

로그인한 로컬 계정 기준으로 학습기록과 오답 현황을 봅니다.

자료 확장 안내

나중에 공개 기출, 복원문제, 강의자료를 source/ 폴더에 넣으면 문제집을 추가할 수 있습니다. 원본 자료는 보관하고, 사이트에는 학습용으로 요약·재구성한 문제와 개념만 반영합니다.
