ADsP 시험 준비 CBT

데이터분석준전문가 시험 대비용 개인 학습 사이트

기본 CBT 시작 개념정리 보기 로그인/회원가입

강의노트로 개념을 잡고, 시험 메뉴에서 CBT와 모의고사를 바로 풀 수 있게 구성했습니다. 오답노트와 학습기록은 하단 토글 메뉴에서 관리합니다.

강의노트

과목별 개념노트

1과목 데이터 이해, 2과목 데이터 분석 기획, 3과목 데이터 분석을 강의노트처럼 정리했습니다.

PDF 기반 요약노트

source PDF에서 확인한 출제 범위를 원문 복제 없이 요약·시각화한 보조 노트입니다.

유튜브 강의 요약

제공한 영상 URL의 한국어 자동자막을 바탕으로 1·2과목 핵심을 강의노트로 재구성했습니다.

유튜브 3과목 요약

3과목 데이터 분석 영상의 자막을 통계·회귀·분류·군집·연관분석 중심으로 정리했습니다.

1·2·3과목 통합 필기노트

강사의 설명을 학생 필기노트처럼 통합 정리하고, 오른쪽 목차로 빠르게 이동할 수 있게 구성했습니다.

시험

ADsP 기본 CBT

핵심 개념을 점검하는 50문항 객관식 문제 풀이입니다.

ADsP 모의고사 1회

시험 흐름에 맞춰 재구성한 50문항 모의고사입니다.

ADsP PDF 심화 CBT

source PDF 원본 내용을 기준으로 1·2·3과목을 실제 시험 비율 10·10·30으로 구성한 심화 50문항입니다.

ADsP PDF 심화 CBT 2회

PDF 원본의 데이터베이스·분석기획·통계·마이닝 세부 개념을 다른 문항으로 재구성했습니다.

ADsP PDF 심화 CBT 3회

PDF 원본 기반 추가 세트로 표 해석, 계산형, 함정형 문제를 섞은 50문항입니다.

ADsP 48회 복원 모의고사

source에 추가한 48회 복원 MD의 문제·정답을 기반으로 선지를 중상 난이도로 재구성했습니다.

ADsP 47회 공개 복원 CBT

공개 복원 후보의 출제 키워드를 기준으로 원문 복제 없이 50문항 CBT로 재구성했습니다.

ADsP 46회 공개 복원 CBT

공개 복원·해설 자료와 공식 범위를 참고해 중상 난이도 4지선다로 정리했습니다.

ADsP 45회 공개 복원 CBT

복원 자료의 키워드를 학습용 문제로 다시 구성하고 출처를 문제 데이터에 남겼습니다.

ADsP 44회 공개 복원 CBT

기출 복원 후보를 그대로 베끼지 않고 시험 대비용 개념 문제로 재작성했습니다.

나중에 공개 기출, 복원문제, 강의자료를 source/ 폴더에 넣으면 문제집을 추가할 수 있습니다. 원본 자료는 보관하고, 사이트에는 학습용으로 요약·재구성한 문제와 개념만 반영합니다.
