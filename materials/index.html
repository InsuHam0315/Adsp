PDF 반영 요약

해제본 PDF는 자동 분석이 가능했고, 사용자가 소유 자료로 공개 가능함을 확인했습니다. 자료실에서 PDF 원본을 열 수 있으며, 과목별 개념노트와 별도 요약 페이지에도 시험 대비용 체크리스트로 재구성했습니다.

원본 관리

공개 가능한 해제본 PDF만 커밋 대상으로 예외 처리했습니다. 기존 암호화 PDF는 중복 파일이므로 계속 Git 커밋 대상에서 제외합니다.
