수동 검수 필요

현재 PDF는 암호화되어 자동 분석이 불가능합니다. 공개 배포 가능한 자료인지, 유료 교재·강의자료 원문이 아닌지 확인한 뒤에만 PDF 링크를 GitHub Pages에 노출해야 합니다.

검수 후 공개 가능하다면 `.gitignore`에서 해당 PDF 제외 규칙을 조정하고, 이 자료실 페이지에 다운로드 링크를 활성화하면 됩니다.
