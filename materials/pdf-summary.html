ADsP는 정의 암기만으로는 헷갈립니다. 예를 들어 DW와 데이터마트, KDD와 CRISP-DM, 정밀도와 재현율처럼 “둘 중 무엇인가”를 묻는 문제가 많습니다.

PDF 반영

원본 + 요약 병행

자료실에서 원본 PDF를 열 수 있고, 이 페이지는 시험용 설명으로 다시 쓴 버전입니다. 모르는 단어가 있으면 이 노트에서 흐름을 보고 원본으로 세부를 확인하세요.

CBT 연결

읽고 바로 풀기

각 과목 핵심을 읽은 뒤 기본 CBT를 풀면 오답이 계정별 학습기록과 오답노트에 저장됩니다.

1과목 데이터 이해

1과목은 “데이터를 어떻게 정의하고, 조직에서 어떻게 저장·활용·관리하는가”를 묻습니다. 용어가 많지만 큰 축은 데이터 개념, 데이터베이스, 빅데이터, 개인정보·윤리, 데이터 사이언스입니다.

개념 1

데이터, 정보, 지식, 지혜

데이터는 아직 해석하지 않은 사실입니다. 정보는 목적에 맞게 가공되어 의미를 가진 데이터이고, 지식은 정보를 활용할 수 있는 패턴과 원리입니다. 지혜는 지식을 상황에 맞게 적용해 판단하는 단계입니다.

Data
사실 Information
의미 Knowledge
활용 원리 Wisdom
판단

시험 포인트: “가공 전 객관적 사실”은 데이터, “패턴 인식”은 정보, “의사결정 활용”은 지식으로 구분합니다.

개념 2

데이터 유형은 기준별로 따로 외운다

구분 기준유형예시암기 포인트
형태정형RDB, 엑셀, CSV행과 열, 스키마가 명확
형태반정형HTML, XML, JSON, RDF메타 구조는 있으나 고정 테이블은 아님
형태비정형SNS, 영상, 음원, 자유문서구조화가 약함
표현정량온도, 풍속, 매출수치로 측정
표현정성기상특보, 주관식 응답언어와 설명 중심
개념 3

데이터베이스와 분석 저장소

데이터베이스는 조직 업무에 필요한 데이터를 저장·관리하는 체계입니다. 시험에서는 DB 자체보다 DBMS, 스키마, 메타데이터, 데이터 사전, 인덱스, SQL 기능을 구분하는 문제가 나옵니다.

용어설명헷갈리는 부분
DBMS데이터베이스 관리 소프트웨어MySQL, Oracle 같은 관리 시스템
스키마DB 구조와 제약조건 명세데이터 값 자체가 아니라 구조
메타데이터데이터를 설명하는 데이터컬럼 의미, 출처, 형식
데이터 사전메타데이터와 구조 정보를 저장시스템 내부 기준 정보
인덱스검색과 정렬을 돕는 보조 구조저장공간은 더 쓰지만 조회를 빠르게 함
SQL 빠른 구분 DDL: CREATE, ALTER, DROP DML: SELECT, INSERT, UPDATE, DELETE DCL: GRANT, REVOKE TCL: COMMIT, ROLLBACK
개념 4

DW, 데이터마트, 데이터레이크

DW는 전사 데이터를 분석 목적으로 통합한 중앙 저장소입니다. 데이터마트는 특정 부서나 주제에 맞춘 작은 분석 저장소입니다. 데이터레이크는 정형·반정형·비정형 원천 데이터를 폭넓게 저장해 이후 분석에 활용하는 구조입니다.

구분목적핵심 키워드
DW전사 의사결정 지원주제지향, 통합, 시계열, 비휘발
ODS운영계 데이터를 임시 통합DW 적재 전 중간 저장
ETL데이터 추출·변환·적재Extraction, Transform, Load
Data Mart부서·주제별 분석DW보다 작고 목적이 좁음
Data Lake다양한 원천 데이터 저장하둡, HDFS, MapReduce와 연결
개념 5

빅데이터와 개인정보

빅데이터는 양이 많은 데이터만 뜻하지 않습니다. 규모, 다양성, 속도에 더해 가치, 신뢰성, 정확성, 휘발성 같은 확장 요소를 함께 봅니다. 개인정보 영역은 개인정보, 가명정보, 익명정보와 비식별 처리 방법을 구분해야 합니다.

3V

Volume, Variety, Velocity

확장 V

Value, Veracity, Validity, Volatility

비식별 처리

가명처리, 총계처리, 삭제, 범주화, 마스킹

시험 포인트: 가명정보는 추가정보 없이는 특정 개인을 알아보기 어렵게 처리한 정보이고, 익명정보는 더 이상 개인 식별이 불가능한 정보입니다.

2과목 데이터 분석 기획

2과목은 분석을 시작하기 전 “문제를 어떻게 찾고, 어떤 방법론과 조직 체계로 실행할 것인가”를 묻습니다. 순서와 구분 문제가 많습니다.

개념 1

분석 방법론 큰 그림

분석 방법론은 절차, 방법, 도구와 기법, 템플릿과 산출물로 구성됩니다. 개발 모델은 폭포수, 프로토타입, 나선형, 애자일을 비교하고, 분석 절차는 KDD와 CRISP-DM 순서를 확실히 외웁니다.

KDD
선택 전처리 변환 마이닝 평가
CRISP-DM
업무 이해 데이터 이해 데이터 준비 모델링 평가 전개
개념 2

하향식, 상향식, 혼합 접근

접근출발점흐름대표 함정
하향식비즈니스 문제문제탐색 → 문제정의 → 해결방안탐색 → 타당성 검토데이터 탐색 출발이 아님
상향식데이터와 현상프로세스 분류 → 프로세스 흐름 분석 → 분석 요건 발굴목적이 없다는 뜻은 아님
혼합발산과 수렴상향식으로 아이디어 발산, 하향식으로 과제 수렴디자인 싱킹과 함께 출제 가능
개념 3

분석 과제와 프로젝트 관리

분석 과제는 정의서와 활용 시나리오가 중요합니다. 정의서는 분석 계획 수립의 입력 자료이고, 활용 시나리오는 분석 결과를 업무에 어떻게 적용할지 설명하는 실행 문서입니다.

분석 과제에서 보는 5요소 데이터 양 데이터 속도 데이터 복잡성 분석 복잡성 정확도와 정밀도 균형

주의: 여기서의 정확도·정밀도는 프로젝트 품질 관점입니다. 3과목 혼동행렬의 Accuracy·Precision과 문맥이 다릅니다.

개념 4

마스터 플랜과 분석 거버넌스

마스터 플랜은 중장기 분석 로드맵입니다. 데이터 기반 의사결정을 조직에 정착시키기 위해 도입, 유효성 검증, 확산·고도화 흐름으로 추진합니다.

구분설명암기 기준
우선순위시급성, 난이도, ROI, 전략 중요도를 함께 평가가치와 실행 가능성
거버넌스조직, 프로세스, 시스템, 데이터, 교육·마인드체계 운영
준비도데이터, 인력, 조직, 분석업무, 기법, 인프라분석을 할 준비가 되었는가
성숙도분석 활용 수준을 단계적으로 진단현재 얼마나 잘 활용하는가
개념 5

분석 조직 구조

구조설명장단점
집중 구조독립 분석 전담 조직전문성은 높지만 현업 중복 이슈 가능
기능 구조현업 부서가 직접 분석업무 이해는 높지만 전담 조직은 없음
분산 구조분석 인력을 현업에 배치전문성과 현업성을 절충

3과목 데이터 분석

3과목은 범위가 넓지만 출제 방식은 비교적 정형적입니다. 전처리, 통계, 회귀, 차원축소, 시계열, 데이터마이닝, 평가 지표를 묶어서 봅니다.

개념 1

데이터 마트, 변수, EDA

분석 데이터는 원천 데이터에서 바로 모델로 가지 않습니다. DW와 데이터마트를 거치며 분석 목적에 맞는 요약변수와 파생변수를 만듭니다. EDA는 통계량과 시각화로 데이터의 특성을 보는 탐색 단계입니다.

구분설명예시
요약변수수집 정보를 종합한 재사용 가능 변수최근 1개월 구매금액
파생변수논리적 의미를 부여해 만든 변수고객구매등급
EDA통계·그래프로 자료 구조 파악저항성, 잔차, 재표현, 시각화
개념 2

결측값과 이상값

결측값은 삭제하거나 대치할 수 있고, 이상값은 오류일 수도 있지만 중요한 신호일 수도 있습니다. 시험에서는 “무조건 제거”가 함정입니다.

결측값 처리

완전분석, 평균대치, Hot-Deck, Cold-Deck, Nearest Neighbor, 다중대치

이상값 탐지

3표준편차, IQR, Z-score, DBSCAN

판단 기준

업무 오류인지 의미 있는 극단값인지 먼저 확인

개념 3

통계 기본과 가설검정

주제핵심 설명시험 문장
척도명목, 서열, 등간, 비율가능한 연산 수준을 묻는다
표본추출랜덤, 계통, 집락, 층화집락은 군집 내 이질, 층화는 층 내 동질
중심극한정리표본크기가 충분하면 표본평균은 정규분포에 가까움모집단 분포와 무관하다는 표현 주의
점추정하나의 값으로 모수를 추정불편성, 효율성, 일치성, 충족성
가설검정p-value와 유의수준 비교p-value < α이면 귀무가설 기각

p-value는 귀무가설이 참일 확률이 아닙니다. 귀무가설이 참이라고 가정했을 때 관측 결과 이상이 나올 확률입니다.

개념 4

회귀분석은 해석 순서가 중요하다

회귀분석은 독립변수로 종속변수를 설명하거나 예측합니다. 먼저 모형 전체가 유의한지 보고, 그다음 개별 회귀계수가 유의한지 봅니다. 다중회귀에서는 R-square보다 수정된 R-square를 함께 확인합니다.

변수 설정 회귀계수 추정 F검정
모형 유의성 t검정
계수 유의성 설명력 확인
회귀 함정 상관은 인과를 보장하지 않음 VIF 10 이상이면 다중공선성 의심 AIC와 BIC는 작을수록 선호 선형성, 등분산성, 정규성, 독립성 확인
개념 5

PCA, MDS, 시계열

기법무엇을 하는가핵심 포인트
PCA상관 높은 변수들을 주성분으로 변환분산이 큰 축, 직교, 설명력, 스크리플롯
MDS거리 정보를 보존해 저차원에 배치Stress 값이 낮을수록 좋음
시계열시간 순서 자료로 미래 예측추세, 계절, 순환, 불규칙 요인
ARIMAAR, 차분, MA를 결합p는 AR, d는 차분, q는 MA
개념 6

데이터 마이닝과 모델 평가

데이터 마이닝은 대량 데이터에서 규칙과 패턴을 찾는 과정입니다. 지도학습은 정답이 있고, 비지도학습은 정답 없이 구조를 찾습니다.

분류대표 기법핵심 설명
지도학습로지스틱 회귀, KNN, 나이브베이즈, 의사결정나무, SVM, 앙상블, 신경망정답 레이블로 분류·회귀 학습
비지도학습군집분석, 연관분석, 차원축소정답 없이 유사성·패턴 탐색
검증Hold-out, K-fold, LOOCV, Bootstrap과대적합과 과소적합 점검
분류 평가 지표 정확도: 전체 중 맞힌 비율 정밀도: 양성 예측 중 실제 양성 재현율: 실제 양성 중 맞힌 비율 F1: 정밀도와 재현율의 조화평균 ROC-AUC: 1에 가까울수록 좋음
개념 7

군집분석과 연관분석

영역핵심 개념시험 포인트
거리유클리디안, 맨하튼, 체비셰프, 민코우스키, 마할라노비스거리 기반 기법은 스케일 영향 주의
연결법최단, 최장, 평균, 중심, 와드계층적 군집에서 사용
K-meansK를 정하고 중심을 반복 갱신초기 중심과 이상치에 민감
DBSCAN밀도 기반 군집K를 사전에 정하지 않아도 되고 노이즈에 강함
연관분석지지도, 신뢰도, 향상도향상도 1보다 크면 양의 연관

핵심 공식 한 장

계산 문제는 많지 않아도, 공식의 의미를 알아야 보기 판단이 빨라집니다. 아래 공식은 ADsP에서 용어와 함께 자주 묶이는 것들입니다.

IQR 이상값 하한 = Q1 - 1.5 × IQR 상한 = Q3 + 1.5 × IQR
표준화 z = (x - μ) / σ
