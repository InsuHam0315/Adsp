반영 방식

PDF 해제본은 텍스트 추출이 가능했고, 사용자가 소유 자료로 공개 가능함을 확인했습니다. 이 페이지는 원문을 그대로 옮기기보다 ADsP 시험 대비 관점에서 주제를 압축하고 설명을 새로 작성한 학습용 요약입니다.

1과목 데이터 이해 체크리스트

  • 데이터와 정보의 차이, DIKW 흐름, 암묵지와 형식지 전환 과정을 함께 암기한다.
  • 데이터 유형은 형태, 표현 방식, 분석 목적 기준으로 나누어 본다.
  • 데이터베이스 특성은 공용성, 통합성, 저장성, 변화성을 중심으로 정리한다.
  • 데이터베이스 설계는 요구분석, 개념 설계, 논리 설계, 물리 설계 순서로 이해한다.
  • DBMS, 스키마, 메타데이터, 데이터 사전, 인스턴스, 인덱스를 구분한다.
  • SQL은 DDL, DML, DCL, TCL의 역할을 비교한다.
  • CRM, SCM, ERP, RTE, BI, BA, KMS는 조직 데이터 활용 시스템으로 묶어 비교한다.
  • DW는 ETL, ODS, 주제지향성, 통합성, 시계열성, 비휘발성을 중심으로 정리한다.
  • 데이터레이크는 원천·비정형 데이터 보관과 하둡 생태계 연결을 함께 본다.
  • 빅데이터는 3V와 확장 V, 가치 산정 어려움, 표본에서 전수로의 변화까지 묻는다.
  • 개인정보, 가명정보, 익명정보와 비식별 처리 방법을 구분한다.
  • 데이터 사이언스는 분석, IT, 비즈니스 이해와 하드·소프트 스킬을 함께 요구한다.

2과목 분석 기획 체크리스트

  • 분석 대상과 방법의 명확성에 따라 최적화, 솔루션, 통찰, 발견형 문제로 구분한다.
  • 방법론 구성요소는 절차, 방법, 도구·기법, 템플릿·산출물이다.
  • 모델 개발 방식은 폭포수, 프로토타입, 나선형, 애자일을 비교한다.
  • KDD는 데이터 선택에서 시작해 전처리, 변환, 마이닝, 평가로 이어진다.
  • CRISP-DM은 업무 이해에서 시작해 전개와 운영 계획까지 포함한다.
  • 빅데이터 분석 방법론은 분석 기획, 데이터 준비, 데이터 분석, 시스템 구현, 평가·전개를 포함한다.
  • 하향식 접근은 문제탐색, 문제정의, 해결방안탐색, 타당성 검토 순서로 본다.
  • 상향식 접근은 데이터 탐색과 프로세스 분류에서 분석 기회를 찾는다.
  • 혼합 접근은 발산 단계의 상향식과 수렴 단계의 하향식을 결합한다.
  • 프로젝트 관리는 데이터 양, 속도, 복잡성, 분석 복잡성, 정확도·정밀도 균형을 고려한다.
  • 분석 로드맵은 도입, 파일럿 검증, 확산·고도화 흐름으로 정리한다.
  • 분석 거버넌스는 조직, 프로세스, 시스템, 데이터, 교육·마인드 체계를 함께 갖춘다.
  • 분석 수준 진단은 준비도와 성숙도를 결합해 준비형, 정착형, 도입형, 확산형으로 해석한다.
  • 분석 조직은 집중 구조, 기능 구조, 분산 구조의 장단점을 비교한다.

3과목 데이터 분석 체크리스트

  • 데이터 마트, 요약변수, 파생변수는 분석 데이터셋 설계 관점에서 구분한다.
  • EDA는 저항성, 잔차, 재표현, 시각화를 통해 데이터의 구조를 확인한다.
  • 결측값은 삭제, 평균 대치, 확률 대치, 다중 대치로 처리할 수 있다.
  • 이상값은 표준편차, IQR, Z-score, 밀도 기반 방법으로 탐지하며 무조건 제거하지 않는다.
  • 척도는 명목, 서열, 등간, 비율로 나누고 가능한 연산 수준을 구분한다.
  • 표본추출은 랜덤, 계통, 집락, 층화, 복원·비복원 방식으로 비교한다.
  • 확률분포는 이산분포와 연속분포를 나누어 대표 예시와 사용 검정을 연결한다.
  • 중심극한정리, 표준오차, 점추정의 조건, 구간추정을 함께 암기한다.
  • 가설검정은 귀무가설, 대립가설, 유의수준, p-value, 단측·양측, 표본 구조를 순서대로 판단한다.
  • 모수 검정과 비모수 검정은 분포 가정 가능 여부와 자료 척도에 따라 선택한다.
  • 회귀분석은 잔차, 최소제곱법, 결정계수, 선형회귀 가정, 다중공선성, 변수 선택 기준을 함께 본다.
  • PCA는 분산을 많이 설명하는 직교 주성분으로 차원을 줄이며, 스크리플롯과 설명력을 확인한다.
  • MDS는 거리 정보의 근접성을 보존해 저차원 공간에 표현한다.
  • 시계열은 추세, 계절, 순환, 불규칙 요인과 정상성, 차분, AR·MA·ARIMA를 연결한다.
  • 데이터 마이닝은 지도학습과 비지도학습을 구분하고 과대적합·과소적합, 교차검증을 함께 이해한다.
  • 분류 알고리즘은 로지스틱 회귀, KNN, 나이브베이즈, 의사결정나무, SVM, 앙상블, 신경망을 비교한다.
  • 평가지표는 혼동행렬, 재현율, 정밀도, F1, ROC-AUC, Lift chart를 상황별로 고른다.
  • 군집분석은 거리 측정, 연결법, K-means, DBSCAN, 실루엣 계수, Elbow Method를 연결한다.
  • 연관분석은 지지도, 신뢰도, 향상도, Apriori, FP-Growth를 묶어 암기한다.

우선 암기 순서

  1. 1과목은 데이터 유형, DW/DM, 빅데이터 V, 개인정보 분류를 먼저 정리한다.
  2. 2과목은 KDD, CRISP-DM, 하향식·상향식, 거버넌스 구성요소를 먼저 정리한다.
  3. 3과목은 가설검정, 회귀, 분류 지표, 군집·연관 지표를 반복 풀이한다.
