2과목 데이터 분석 기획

분석 방법론은 절차·방법·도구·산출물

방법론 문제는 이름보다 순서와 단계별 수행 내용을 묻습니다. 폭포수는 순차 진행, 프로토타입은 시제품 피드백, 나선형은 위험 제거, 애자일은 짧은 반복 개발로 정리합니다.

KDD와 CRISP-DM 순서

KDD

데이터 선택 → 전처리 → 변환 → 데이터 마이닝 → 해석·평가

CRISP-DM

업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개

“모델 작성 및 평가”는 이름 때문에 평가 단계로 착각하기 쉽지만, CRISP-DM에서는 모델링 단계에서 수행합니다.

3과목 데이터 분석

데이터 마트와 전처리

3과목은 데이터 마트에서 시작합니다. 요약 변수는 평균·합계처럼 정보를 종합한 변수이고, 파생 변수는 고객 등급처럼 논리적 타당성을 부여한 변수입니다.

전처리필기 포인트
결측치삭제, 평균 대치, 조건부 평균 대치, 확률 대치
이상치오류인지 의미 있는 극단값인지 먼저 판단
척도명목·서열은 질적, 등간·비율은 양적 척도

기초 통계와 확률분포

평균은 이상치에 민감하고 중앙값은 상대적으로 강건합니다. 공분산과 상관계수는 선형 관계를 보며, 독립이면 공분산은 0이지만 공분산이 0이라고 항상 독립은 아닙니다.

표준화Z = (X - μ) / σ
조건부확률P(A|B) = P(A∩B) / P(B)
변동계수CV = s / x̄

추론통계와 가설검정

추론통계는 표본으로 모집단을 추정하거나 검정합니다. 중심극한정리는 표본평균의 분포가 정규분포에 가까워진다는 점 때문에 추정과 검정의 기반이 됩니다.

p-value는 “귀무가설이 참일 확률”이 아니라, 귀무가설 하에서 관측 결과 이상이 나올 확률입니다.

회귀분석과 PCA

회귀분석은 독립변수와 종속변수의 관계를 설명하고 예측합니다. 다중회귀는 여러 독립변수를 쓰므로 다중공선성을 조심해야 합니다. PCA는 상관 높은 변수들의 선형결합으로 차원을 줄입니다.

선형성 정규성 등분산성 독립성

분류·군집·연관분석

분류

정답이 있는 지도학습. 로지스틱 회귀, KNN, 나이브 베이즈, 의사결정나무, SVM, 신경망.

군집

정답 없이 유사도와 거리로 묶는 비지도학습. K-means, 계층적 군집, DBSCAN.

연관

장바구니 규칙. 지지도, 신뢰도, 향상도를 구분한다.

연관분석 지표계산 감각
지지도A와 B가 동시에 포함된 거래 / 전체 거래
신뢰도A와 B가 동시에 포함된 거래 / A가 포함된 거래
향상도신뢰도 / B의 지지도

시험 직전 체크

자주 틀리는 함정

  • 데이터와 정보는 가공 여부로 구분한다.
  • 반정형은 XML·JSON처럼 구조는 있지만 고정 테이블은 약하다.
  • CRISP-DM의 모델 작성 및 평가는 모델링 단계이다.
  • 상향식 접근은 비지도학습, 프로토타이핑과 연결된다.
  • 상자그림 이상치는 평균·표준편차가 아니라 IQR 기준이다.
  • p-value는 귀무가설이 참일 확률이 아니다.
  • 공분산 0은 독립을 보장하지 않는다.
  • PCA는 뒤 주성분으로 갈수록 설명분산이 감소한다.
  • 신뢰도와 지지도 계산식의 분모를 바꿔 쓰지 않는다.
