1과목 데이터 이해

가장 먼저 구분

데이터와 정보

데이터는 있는 그대로의 객관적 사실이고, 정보는 데이터를 목적에 맞게 가공해 의미를 부여한 자료입니다. 시험에서는 “가공 여부”와 “의사결정에 쓸 수 있는 의미가 생겼는가”로 구분합니다.

주문 수량
원자료 월별 판매량 집계
가공 베스트셀러 판단
정보 활용
DIKW

Data → Information → Knowledge → Wisdom

DIKW는 아래로 갈수록 원자료에 가깝고, 위로 갈수록 판단과 실행에 가까워집니다. 지식은 정보 간 관계와 원리를 이해한 상태이고, 지혜는 그 지식을 상황에 맞게 적용하는 판단력입니다.

Wisdom: 상황에 맞는 판단
Knowledge: 관계와 원리 이해
Information: 목적에 맞게 가공된 의미
Data: 관찰·측정된 사실
데이터 유형

정형·반정형·비정형

정형

행과 열 구조가 명확한 고객 테이블, 거래 테이블.

반정형

HTML, XML, JSON처럼 태그·메타데이터가 있는 자료.

비정형

SNS 글, 이미지, 영상, 음성처럼 고정 스키마가 약한 자료.

영상에서는 사례 구분이 자주 출제된다고 강조합니다. “데이터베이스에 저장된 행·열”은 정형, “태그나 메타데이터”는 반정형, “영상·음성·자유 텍스트”는 비정형으로 빠르게 판단합니다.

저장소

DB, DBMS, 메타데이터, DW, 데이터 레이크

개념시험식 구분주의점
데이터베이스공용·통합·저장·변화 데이터여러 사용자가 공동 이용
DBMSDB를 관리하는 소프트웨어저장, 검색, 갱신, 권한, 무결성 관리
메타데이터데이터를 설명하는 데이터데이터 사전, 스키마와 연결
데이터웨어하우스전사 분석용 통합 저장소주제 중심, 통합, 시계열, 비휘발
데이터 레이크정형·비정형을 원천에 가깝게 저장DW보다 형식 제약이 약함
빅데이터

3V, 가치 패러다임, 위기 요인

Volume

처리해야 할 데이터 양이 매우 큼.

Velocity

발생·수집·처리 속도가 빠름.

Variety

정형, 반정형, 비정형이 함께 존재.

Digitalization Connection Agency

위기 요인은 사생활 침해, 책임 원칙 훼손, 데이터 오용을 중심으로 정리합니다. 데이터 3법과 비식별 처리도 함께 묶어 암기합니다.

2과목 데이터 분석 기획

방법론

방법론 구성 요소와 개발 모델

방법론은 “어떤 절차로, 어떤 방법·도구·기법을 쓰고, 어떤 산출물이 나오는가”를 정리한 체계입니다.

모델핵심시험 포인트
폭포수위에서 아래로 순차 진행되돌아가기 어려움
프로토타입일부 모델을 먼저 만들고 피드백 반영요구사항 불명확할 때 유용
나선형반복하면서 점진적으로 완성위험 요소 제거 강조
애자일짧은 주기의 반복 개발지속적 피드백 반영
순서 암기

KDD, CRISP-DM, 빅데이터 분석 방법론

KDD
선택 전처리 변환 마이닝 평가

CRISP-DM은 업무 이해, 데이터 이해, 데이터 준비, 모델링, 평가, 전개 순서입니다. 영상에서는 “모델 작성 및 평가는 모델링 단계”라는 함정과, 평가 후 전개 과정에서 다시 업무 이해로 돌아갈 수 있다는 점을 강조합니다.

빅데이터 분석 방법론은 단계-태스크-스텝의 계층 구조를 기반으로 하며, 분석 기획, 데이터 준비, 데이터 분석, 시스템 구현, 평가 및 전개 흐름으로 정리합니다.

과제 발굴

하향식·상향식·혼합 접근

접근법출발점연결 개념
하향식문제와 목표가 먼저 있음문제 탐색 → 문제 정의 → 해결방안 탐색 → 타당성 검토
상향식문제 정의가 어려움데이터 탐색, 비지도학습, 프로토타이핑
혼합발산과 수렴을 함께 사용디자인 싱킹

상향식은 “정답이 없는 문제”와 연결되어 비지도학습이 자주 붙습니다. 하향식은 비즈니스 문제에서 출발합니다.

마스터 플랜

우선순위, 로드맵, 거버넌스

IT 프로젝트 우선순위는 전략적 중요도와 실행 용이성 관점으로 보고, 데이터 분석 과제는 시급성과 난이도 관점으로 봅니다. 시급성은 비즈니스 효과, 난이도는 데이터 양·속도·다양성과 같은 3V 관점과 연결됩니다.

분석 거버넌스는 조직, 프로세스, 시스템, 데이터, 교육·마인드 체계를 포함합니다. 데이터 거버넌스는 원칙, 조직, 프로세스를 중심으로 표준·품질·보안·메타데이터·마스터데이터를 관리합니다.

  4. 데이터웨어하우스와 데이터 레이크의 차이를 설명하라.
  5. 빅데이터 3V와 위기 요인 3가지를 쓰라.
  6. CRISP-DM에서 데이터 준비와 모델링 사이의 관계를 설명하라.
  7. 상향식 접근법이 비지도학습과 연결되는 이유를 설명하라.
