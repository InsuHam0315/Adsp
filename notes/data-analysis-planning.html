분석 과제 발굴, 프로젝트 관리, 방법론, 거버넌스와 우선순위 평가를 정리합니다.

과목 개요

데이터 분석 기획은 분석을 시작하기 전 문제를 정의하고, 과제를 발굴하며, 우선순위와 실행 계획을 수립하는 영역이다. 분석 방법론과 관리 체계를 구분하는 문제가 자주 나온다.

시험에 나오는 핵심

  • 하향식 접근법과 상향식 접근법의 출발점을 구분한다.
  • 분석 과제 정의서에 들어갈 목적, 범위, 데이터, 기대효과를 이해한다.
  • 분석 프로젝트의 일정, 범위, 품질, 위험 관리를 파악한다.
  • 마스터 플랜, 거버넌스, 성숙도, 준비도를 관리 체계로 연결한다.
  • ROI, 시급성, 난이도, 기대가치로 우선순위를 평가한다.
  • CRISP-DM, KDD, 빅데이터 분석 방법론의 단계 순서를 구분한다.

핵심 개념 정리

분석 기획의 개념

분석 기획은 비즈니스 문제를 데이터 분석 과제로 전환하고, 필요한 데이터와 방법, 일정, 성과 기준을 정하는 활동이다. 좋은 기획은 문제 정의와 실행 가능성을 동시에 갖춘다.

분석 과제 발굴

과제 발굴은 비즈니스 이슈, 업무 프로세스, 고객 경험, 데이터 탐색, 선진 사례를 통해 분석 기회를 찾는 과정이다. 발굴된 아이디어는 가치와 실행 가능성을 기준으로 선별한다.

하향식 접근법과 상향식 접근법

하향식 접근법은 비즈니스 문제나 전략 목표에서 출발해 분석 과제를 정의한다. 상향식 접근법은 보유 데이터 탐색에서 출발해 패턴과 인사이트를 찾아 과제를 도출한다.

분석 과제 정의

분석 과제 정의는 문제 배경, 분석 목적, 범위, 활용 데이터, 분석 방법, 산출물, 기대효과, 제약사항을 명확히 적는 단계다. 정의가 모호하면 모델 성능보다 실행 실패 위험이 커진다.

분석 프로젝트 관리

분석 프로젝트는 범위, 일정, 비용, 품질, 인력, 의사소통, 위험을 관리한다. 데이터 확보 지연, 품질 문제, 요구사항 변경, 모델 적용 실패가 대표 위험이다.

분석 마스터 플랜

분석 마스터 플랜은 조직 차원의 분석 과제 포트폴리오와 추진 로드맵이다. 단기 성과와 장기 역량 확보를 함께 고려해 과제 우선순위와 실행 순서를 정한다.

분석 거버넌스, 성숙도 모델, 분석 준비도

분석 거버넌스는 분석 조직, 역할, 프로세스, 데이터, 플랫폼, 성과관리를 정렬하는 체계다. 성숙도 모델은 조직의 현재 분석 역량 수준을 단계적으로 평가한다. 분석 준비도는 데이터, 인력, 기술, 문화, 업무 프로세스가 분석 수행에 적합한지 보는 관점이다.

ROI 관점과 우선순위 평가

ROI 관점에서는 기대 수익 또는 효과와 투자 비용을 비교한다. 우선순위는 전략적 중요도, 시급성, 실행 난이도, 데이터 확보 가능성, 기대효과를 종합해 결정한다.

CRISP-DM

CRISP-DM은 비즈니스 이해, 데이터 이해, 데이터 준비, 모델링, 평가, 전개의 순서로 진행되는 대표 분석 방법론이다.

KDD 분석 절차

KDD는 데이터 선택, 전처리, 변환, 데이터 마이닝, 해석·평가 단계로 지식 발견을 수행한다. 시험에서는 CRISP-DM과 단계 명칭을 비교해 묻는다.

빅데이터 분석 방법론

빅데이터 분석 방법론은 분석 기획, 데이터 준비, 데이터 분석, 시스템 구현, 평가 및 전개처럼 대규모 데이터 처리와 운영 반영을 포함한다. 데이터 수집·저장·처리 인프라 고려가 중요하다.

시험 함정 포인트

  1. 하향식 접근법은 데이터가 아니라 비즈니스 문제에서 시작한다.
  2. 상향식 접근법은 목적이 전혀 없다는 뜻이 아니라 데이터 탐색에서 기회를 찾는 방식이다.
  3. 분석 과제 정의에는 모델 알고리즘만 쓰는 것이 아니라 목적과 활용 방안이 포함된다.
  4. 분석 마스터 플랜은 단일 모델 개발 계획보다 넓은 조직 차원의 로드맵이다.
  5. ROI는 효과만 보는 것이 아니라 비용과 투자 대비 성과를 함께 본다.
  6. Quick Win은 난이도가 낮고 효과가 빠른 과제에 가깝다.
  7. CRISP-DM의 첫 단계는 비즈니스 이해다.
  8. KDD의 데이터 마이닝은 전체 절차 중 한 단계이지 KDD 전체와 동일하지 않다.
  9. 분석 준비도는 도구 보유 여부만이 아니라 인력·문화·프로세스까지 포함한다.
  10. 빅데이터 분석 방법론은 분석뿐 아니라 데이터 처리 인프라와 전개까지 고려한다.

예상문제

  1. 비즈니스 문제에서 출발해 분석 과제를 찾는 방식은? 정답: 하향식 접근법
  2. 보유 데이터를 탐색해 분석 기회를 찾는 방식은? 정답: 상향식 접근법
  3. 분석 과제 정의서에 포함되기 어려운 것은? 정답: 무관한 개인 취미 정보
  4. 난이도는 낮고 효과가 빨라 우선 추진하기 좋은 과제는? 정답: Quick Win
  5. CRISP-DM의 첫 단계는? 정답: 비즈니스 이해
  6. KDD에서 데이터 마이닝 뒤에 수행하는 단계는? 정답: 해석·평가
  7. 조직의 분석 기반 충족 여부를 보는 관점은? 정답: 분석 준비도
  8. 투자 대비 효과 관점에서 과제 우선순위를 보는 기준은? 정답: ROI

최종 암기 요약

  1. 분석 기획은 문제를 분석 가능한 과제로 바꾸는 활동이다.
  2. 하향식은 문제·전략에서 출발한다.
  3. 상향식은 데이터 탐색에서 출발한다.
  4. 과제 정의서는 목적, 범위, 데이터, 방법, 산출물, 기대효과를 포함한다.
  5. 분석 프로젝트는 범위, 일정, 품질, 위험 관리가 중요하다.
  6. 마스터 플랜은 조직 차원의 분석 과제 로드맵이다.
  7. 분석 거버넌스는 조직, 역할, 프로세스, 플랫폼, 성과관리 체계다.
  8. 성숙도는 현재 분석 활용 수준을 본다.
  9. 준비도는 분석 수행 기반을 본다.
  10. ROI는 기대효과와 비용을 함께 보는 관점이다.
  11. CRISP-DM 순서는 비즈니스 이해에서 시작해 전개로 끝난다.
  12. KDD는 선택, 전처리, 변환, 마이닝, 해석·평가 흐름이다.
