제1과목 데이터 이해

데이터의 의미, 데이터베이스, 빅데이터, 데이터 가치와 관리 체계를 정리합니다.

개념정리 목록 메인으로 돌아가기 관련 CBT 풀러 가기

과목 개요

데이터 이해는 ADsP의 출발점이다. 데이터가 정보와 지식으로 바뀌는 과정, 데이터베이스와 데이터웨어하우스의 역할, 빅데이터가 만드는 가치, 데이터 윤리와 거버넌스를 구분해 묻는다.

시험에 나오는 핵심

  • 데이터, 정보, 지식, 지혜의 단계 차이를 설명할 수 있어야 한다.
  • 정형·반정형·비정형 데이터의 예시를 구분해야 한다.
  • 데이터베이스, 데이터웨어하우스, 데이터마트의 목적과 범위를 비교해야 한다.
  • 빅데이터의 3V와 5V를 암기하고 의미를 연결해야 한다.
  • 데이터 가치 창출과 데이터 사이언스의 구성 요소를 이해해야 한다.
  • 개인정보, 데이터 윤리, 데이터 품질, 데이터 거버넌스를 관리 관점에서 구분해야 한다.

핵심 개념 정리

데이터의 개념

데이터는 관찰·측정·수집된 사실 또는 값이다. 그 자체만으로는 의미가 약할 수 있지만, 맥락과 해석이 더해지면 정보가 되고 의사결정의 근거가 된다.

DIKW 피라미드

  • Data: 가공 전 사실과 수치
  • Information: 목적에 맞게 처리되어 의미가 생긴 데이터
  • Knowledge: 정보 사이의 패턴과 원리를 이해한 상태
  • Wisdom: 지식을 바탕으로 올바른 판단과 실행을 하는 능력

데이터 유형

정형 데이터는 행과 열처럼 정해진 구조가 있다. 반정형 데이터는 XML, JSON처럼 태그나 메타데이터가 있으나 고정 스키마가 약하다. 비정형 데이터는 문서, 이미지, 음성, 영상처럼 정형화된 테이블로 바로 다루기 어렵다.

데이터베이스, 데이터웨어하우스, 데이터마트

데이터베이스는 특정 업무의 데이터를 체계적으로 저장·관리하는 시스템이다. 데이터웨어하우스는 의사결정을 위해 여러 시스템의 데이터를 통합해 주제 중심, 통합성, 시계열성, 비휘발성 특성을 갖는다. 데이터마트는 부서나 특정 분석 목적에 맞춰 데이터웨어하우스의 일부를 작게 구성한 것이다.

빅데이터 개념과 3V·5V

빅데이터는 기존 방식으로 저장·처리·분석하기 어려운 대규모·다양한 데이터와 그 활용 체계를 말한다. 3V는 Volume, Velocity, Variety이며 5V는 여기에 Veracity와 Value를 더해 데이터 신뢰성과 가치 창출을 강조한다.

데이터 가치와 데이터 사이언스

데이터 가치는 문제 해결, 의사결정 개선, 새로운 서비스 창출, 운영 최적화에서 발생한다. 데이터 사이언스는 통계·수학, 컴퓨팅, 도메인 지식을 결합해 데이터를 분석하고 실행 가능한 통찰을 만드는 활동이다.

데이터 윤리와 개인정보

데이터 활용은 목적 적합성, 최소 수집, 안전한 보관, 비식별 처리, 편향 완화, 설명 가능성을 고려해야 한다. 개인정보는 개인을 식별할 수 있는 정보이며 결합 가능성까지 함께 판단한다.

데이터 거버넌스와 데이터 품질

데이터 거버넌스는 데이터의 정책, 표준, 책임, 절차를 정해 전사적으로 관리하는 체계다. 데이터 품질은 정확성, 완전성, 일관성, 적시성, 유효성 같은 기준으로 평가한다.

시험 함정 포인트

  1. DIKW에서 정보는 단순 수치가 아니라 목적에 맞게 처리된 데이터다.
  2. JSON은 테이블 구조가 명확하지 않아 보통 반정형 데이터로 본다.
  3. 데이터웨어하우스는 운영 트랜잭션 처리보다 분석과 의사결정 지원이 목적이다.
  4. 데이터마트는 데이터웨어하우스보다 범위가 작고 특정 목적에 맞다.
  5. 빅데이터 3V의 Variety는 데이터 유형의 다양성을 뜻한다.
  6. 5V의 Veracity는 속도가 아니라 신뢰성·정확성 문제와 관련된다.
  7. 개인정보는 이름만이 아니라 다른 정보와 결합해 식별 가능한 정보도 포함한다.
  8. 데이터 거버넌스는 기술 도구 하나가 아니라 정책·조직·책임·절차의 체계다.
  9. 데이터 품질의 적시성은 필요한 시점에 사용할 수 있는지를 본다.
  10. 데이터 사이언스는 통계만이 아니라 컴퓨팅과 도메인 이해가 함께 필요하다.

예상문제

  1. DIKW 피라미드에서 데이터에 맥락을 부여해 의미 있게 만든 단계는? 정답: 정보
  2. JSON과 XML이 일반적으로 분류되는 데이터 유형은? 정답: 반정형 데이터
  3. 전사 데이터를 통합해 의사결정을 지원하는 저장소는? 정답: 데이터웨어하우스
  4. 빅데이터 3V가 아닌 것은? 정답: Validity
  5. 5V에서 데이터의 신뢰성과 관련된 요소는? 정답: Veracity
  6. 고객·상품처럼 여러 시스템에서 공통으로 쓰이는 기준 데이터는? 정답: 마스터 데이터
  7. 데이터 관리 정책과 책임을 정하는 체계는? 정답: 데이터 거버넌스
  8. 데이터가 필요한 시점에 제공되는지를 보는 품질 기준은? 정답: 적시성

최종 암기 요약

  1. 데이터는 사실, 정보는 목적에 맞게 처리된 의미다.
  2. DIKW 순서는 Data, Information, Knowledge, Wisdom이다.
  3. 정형 데이터는 스키마가 명확한 테이블 데이터다.
  4. 반정형 데이터의 대표 예시는 XML, JSON이다.
  5. 비정형 데이터는 문서, 이미지, 음성, 영상처럼 구조화가 어렵다.
  6. 데이터웨어하우스는 주제 중심, 통합성, 시계열성, 비휘발성을 갖는다.
  7. 데이터마트는 특정 부서나 분석 목적 중심의 작은 저장소다.
  8. 빅데이터 3V는 규모, 속도, 다양성이다.
  9. 빅데이터 5V는 3V에 신뢰성과 가치를 더한다.
  10. 데이터 사이언스는 통계, 컴퓨팅, 도메인 지식의 결합이다.
  11. 개인정보는 결합 가능성까지 고려해 식별성을 판단한다.
  12. 거버넌스는 관리 체계, 품질은 데이터 상태의 수준이다.
