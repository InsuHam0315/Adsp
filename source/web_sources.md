# 공개 웹 복원 후보 기록

이 문서는 ADsP 공개 복원문제 후보를 확인하고 사이트에 반영한 기준을 기록합니다. 공개 웹 자료를 그대로 대량 복제하지 않고, 출제 키워드와 공식 범위를 바탕으로 학습용 CBT 문제를 재구성했습니다.

## 확인한 공개 후보

| 구분 | URL | 확인 내용 | 반영 방식 |
|---|---|---|---|
| 공식 범위 | https://www.dataq.or.kr/www/sub/a_06.do | 국가공인 데이터분석준전문가(ADsP) 시험 안내 및 공식 범위 확인 | 과목명과 큰 출제 범위 검증 기준으로 사용 |
| 44~48회 복원 후보 | https://history-ryan.tistory.com/10 | 44~48회 복원 PDF 링크와 복원 자료의 한계 안내 확인 | 원문 복제 없이 회차별 키워드 기반 CBT 재구성 |
| 46회 복원/해설 후보 | https://yddaily.com/data-analysis-adsp-past-exam-46th-restored/ | 46회 출제 방향과 복원/해설 자료 후보 확인 | 46회 CBT의 출제 키워드 참고 |

## 제외한 자료

| 자료 유형 | 제외 이유 |
|---|---|
| 검색 결과에 노출된 유료·구독형 문서 사이트 | 공개 배포 권한이 불명확함 |
| 원문 전체를 복사해야만 활용 가능한 페이지 | 저작권·재배포 위험이 있어 제외 |
| 출처·회차·정답 신뢰도가 불분명한 게시물 | CBT 데이터로 반영하지 않음 |

## 검수 메모

- 각 문제의 `source` 필드에 공개 웹 후보와 공식 범위 참조 사실을 기록했습니다.
- 실제 시험 원문·선지와 동일함을 보장하지 않습니다.
- 복원 자료는 응시자 기억 기반일 수 있으므로 오류 가능성이 있습니다.
- 공개 자료를 추가로 확보하면 `source/`에 저장한 뒤 문제·정답·출처를 사람이 검수해야 합니다.
